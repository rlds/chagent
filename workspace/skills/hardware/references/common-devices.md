# 常用 I2C/SPI 设备参考

## I2C 设备

### AHT20 — 温湿度传感器
- **地址：** 0x38
- **初始化：** 写入 `[0xBE, 0x08, 0x00]`，然后等待 10ms
- **测量：** 写入 `[0xAC, 0x33, 0x00]`，等待 80ms，读取 6 字节
- **解析：** 状态=byte[0]，湿度=(byte[1]<<12|byte[2]<<4|byte[3]>>4)/2^20*100，温度=(byte[3]&0x0F<<16|byte[4]<<8|byte[5])/2^20*200-50
- **说明：** 无寄存器寻址 —— 直接写入命令字节（省略 `register` 参数）

### BME280 / BMP280 — 温度、湿度、气压
- **地址：** 0x76 或 0x77（由 SDO 引脚选择）
- **芯片 ID 寄存器：** 0xD0 → BMP280=0x58，BME280=0x60
- **数据寄存器：** 0xF7-0xFE（气压、温度、湿度）
- **配置：** 写入 0xF2（湿度过采样）、0xF4（温度/气压过采样 + 模式）、0xF5（待机时间、滤波）
- **强制测量：** 向寄存器 0xF4 写入 `[0x25]`，等待 40ms，从 0xF7 读取 8 字节
- **校准：** 从 0x88 读取 26 字节、从 0xE1 读取 7 字节，用于补偿公式
- **也可通过 SPI 使用**（模式 0 或 3）

### SSD1306 — 128x64 OLED 显示屏
- **地址：** 0x3C（若 SA0 为高电平则为 0x3D）
- **命令前缀：** 0x00（写入寄存器 0x00）
- **数据前缀：** 0x40（写入寄存器 0x40）
- **初始化序列：** `[0xAE, 0xD5, 0x80, 0xA8, 0x3F, 0xD3, 0x00, 0x40, 0x8D, 0x14, 0x20, 0x00, 0xA1, 0xC8, 0xDA, 0x12, 0x81, 0xCF, 0xD9, 0xF1, 0xDB, 0x40, 0xA4, 0xA6, 0xAF]`
- **开启显示：** 0xAF，**关闭显示：** 0xAE
- **也可通过 SPI 使用**（速度更快，推荐用于动画）

### MPU6050 — 六轴加速度计 + 陀螺仪
- **地址：** 0x68（若 AD0 为高电平则为 0x69）
- **WHO_AM_I：** 寄存器 0x75 → 应返回 0x68
- **唤醒：** 向寄存器 0x6B 写入 `[0x00]`（清除休眠位）
- **读取加速度：** 从寄存器 0x3B 读取 6 字节（XH、XL、YH、YL、ZH、ZL）—— 有符号 16 位，默认量程 ±2g
- **读取陀螺仪：** 从寄存器 0x43 读取 6 字节 —— 有符号 16 位，默认量程 ±250°/s
- **读取温度：** 从寄存器 0x41 读取 2 字节 —— 温度°C = value/340 + 36.53

### DS3231 — 实时时钟
- **地址：** 0x68
- **读取时间：** 从寄存器 0x00 读取 7 字节（秒、分、时、星期、日、月、年）—— BCD 编码
- **设置时间：** 向寄存器 0x00 写入 7 个 BCD 字节
- **温度：** 从寄存器 0x11 读取 2 字节（有符号，分辨率 0.25°C）
- **状态：** 寄存器 0x0F —— 第 2 位 = 忙，第 0 位 = 闹钟 1 标志

### INA219 — 电流与功率监测器
- **地址：** 0x40-0x4F（A0、A1 引脚可选）
- **配置：** 寄存器 0x00 —— 设置电压范围、增益、ADC 分辨率
- **分流电压：** 寄存器 0x01（有符号 16 位，LSB=10µV）
- **总线电压：** 寄存器 0x02（位 15:3，LSB=4mV）
- **功率：** 寄存器 0x03（校准后可用）
- **电流：** 寄存器 0x04（校准后可用）
- **校准：** 寄存器 0x05 —— 根据分流电阻值设置

### PCA9685 — 16 通道 PWM / 舵机控制器
- **地址：** 0x40-0x7F（A0-A5 可选，默认 0x40）
- **模式 1：** 寄存器 0x00 —— 第 4 位=休眠，第 5 位=自动递增
- **设置 PWM 频率：** 休眠 → 将预分频值写入 0xFE → 唤醒。预分频值 = round(25MHz / (4096 × freq)) - 1
- **通道 N 的开关：** 寄存器 0x06+4*N 至 0x09+4*N（ON_L、ON_H、OFF_L、OFF_H）
- **舵机 0°-180°：** ON=0，OFF=150-600（50Hz 下）。典型值：0°=150、90°=375、180°=600

### AT24C256 — 256Kbit EEPROM
- **地址：** 0x50-0x57（A0-A2 可选）
- **读取：** 写入 2 字节地址（高、低），然后读取 N 字节
- **写入：** 写入 2 字节地址 + 最多 64 字节（页写入），等待 5ms 完成写周期
- **页大小：** 64 字节。跨越页边界的写入会回卷。

## SPI 设备

### MCP3008 — 8 通道 10 位 ADC
- **接口：** SPI 模式 0，5V 下最高 3.6 MHz
- **读取通道 N：** 发送 `[0x01, (0x80 | N<<4), 0x00]`，结果位于第 1-2 字节的最后 10 位
- **公式：** value = ((byte[1] & 0x03) << 8) | byte[2]
- **电压：** value × Vref / 1024

### W25Q128 — 128Mbit SPI 闪存
- **接口：** SPI 模式 0 或 3，最高 104 MHz
- **读取 ID：** 发送 `[0x9F, 0, 0, 0]` → 厂商 ID + 设备 ID
- **读取数据：** 发送 `[0x03, addr_high, addr_mid, addr_low]` + N 个零字节
- **状态：** 发送 `[0x05, 0]` → 第 0 位 = BUSY
