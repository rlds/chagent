# 任务清单

本文件只记录未完成任务。全部任务完成后，已完成的条目移入 [TASK_LOG.md](TASK_LOG.md)，本文件恢复为“无”。

## 格式

```markdown
### TASK-YYYYMMDD-NNN 任务标题

- 创建时间：YYYY-MM-DDTHH:MM:SS+08:00
- 来源：用户会话 / 调度器 / 遗留任务
- 身份类型与职责（必填）：前端/后端/架构/SRE/硬件研发/产品设计/产品开发/运营/商品运营/销售/市场公关/政府关系/财务/投资融资/审计/法务/人力/管理层 等；职责边界、专业标准与验收责任
- 公司类型（如已判定，可选）：电商 / 生鲜电商 / 半导体 / 芯片设计 / AI / 机械设计 / 无人机 / 机器人 / 餐饮 等
- 状态：pending | in_progress | blocked | abandoned
- 目标：可验证的结果
- 验收标准：
  - ...
- 证据：
  - ...
```

编号创建后不复用；状态必须与实际执行一致。
